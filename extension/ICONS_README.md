# Extension Icons

The Chrome extension references two icon files:
- `icon48.png` (48x48 pixels)
- `icon128.png` (128x128 pixels)

These are optional - the extension will work without them, but Chrome will use default icons.

To add proper icons:
1. Create 48x48 and 128x128 pixel PNG images with a truck/logistics theme
2. Name them `icon48.png` and `icon128.png`
3. Place them in this `extension/` folder

For now, the extension works fine without custom icons.
