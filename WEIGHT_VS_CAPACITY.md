# 📊 Weight vs Capacity - Пояснення різниці

## 🎯 Основна різниця

### Weight (Вага вантажу) 📦
- **Що це:** Вага конкретного вантажу, який потрібно перевезти
- **Приклад:** У вас є товар вагою 3.5 тонни
- **В API:** `load_weight: { from: 0, to: 3.5 }`
- **Використання:** Фільтрує пропозиції за вагою вантажу

### Capacity (Вантажопідйомність транспорту) 🚛
- **Що це:** Максимальна вага, яку може перевозити транспортний засіб
- **Приклад:** Вантажівка може перевозити до 12 тонн
- **В API:** `cargo_capacity: { from: 3.5, to: 12 }`
- **Використання:** Фільтрує транспорт за його можливостями

## 📋 Практичні приклади

### Приклад 1: Легкий вантаж
```
Вантаж: 2 тонни (Weight)
Потрібен транспорт: мінімум 2 тонни вантажопідйомності (Min Capacity)
Підійде: Бус (до 3.5т), Вантажівка (до 12т), Фура (до 40т)
```

### Приклад 2: Важкий вантаж
```
Вантаж: 15 тонн (Weight)
Потрібен транспорт: мінімум 15 тонн вантажопідйомності (Min Capacity)
Підійде: Тільки фура (до 40т)
НЕ підійде: Бус (до 3.5т), Вантажівка (до 12т)
```

### Приклад 3: Ваш випадок
```
Фільтр на Trans.eu: максимум 3.5т (Max Weight)
Означає: шукаємо вантажі вагою до 3.5 тонн
Транспорт: повинен мати вантажопідйомність мінімум 3.5т (Min Capacity)
```

## 🔧 Налаштування в Larry Route Planner

### Weight (Вага вантажу)
- **Min Weight:** Мінімальна вага вантажу для пошуку
- **Max Weight:** Максимальна вага вантажу для пошуку
- **Джерело:** Зчитується з фільтрів Trans.eu автоматично

### Capacity (Вантажопідйомність)
- **Min Capacity:** Мінімальна вантажопідйомність транспорту
- **Max Capacity:** Максимальна вантажопідйомність транспорту
- **Джерело:** Може зчитуватися з секції "Курси" на Trans.eu

## 🎛️ Як це працює в Trans.eu


## 🚀 Рекомендації

### Для пошуку вантажів:
1. **Встановіть Max Weight** відповідно до можливостей вашого транспорту
2. **Min Weight = 0** (або порожнє) щоб не пропустити легкі вантажі
3. **Min Capacity** встановіть відповідно до ваги вашого вантажу

### Для оптимізації:
- Якщо у вас бус (3.5т): `Max Weight = 3.5, Min Capacity = 0`
- Якщо у вас вантажівка (12т): `Max Weight = 12, Min Capacity = 0`
- Якщо у вас фура (40т): `Max Weight = 40, Min Capacity = 0`

## 🔍 Налагодження

Перевірте правильність налаштувань:
```javascript
// В консолі браузера
console.log('Config:', {
  minWeight: config.minWeight,     // Мін. вага вантажу
  maxWeight: config.maxWeight,     // Макс. вага вантажу  
  minCapacity: config.minCapacity, // Мін. вантажопідйомність
  maxCapacity: config.maxCapacity  // Макс. вантажопідйомність
});
```

Очікуваний результат для вашого випадку:
```javascript
{
  minWeight: 0,        // Порожнє поле на Trans.eu
  maxWeight: 3.5,      // Значення з Trans.eu
  minCapacity: 0,      // За замовчуванням
  maxCapacity: undefined // Не встановлено
}
```
