# Архітектура New Strategy

## Призначення компонентів

### roadOptimizer.ts
Цей файл призначений суто для того, щоб реалізувати алгоритм пошуку та формувати маршрути.

**Основні функції:**
- Реалізація алгоритмів оптимізації маршрутів
- Пошук найкращих варіантів доставки
- Формування оптимальних маршрутів на основі різних критеріїв

### redisRouteService.ts
Цей файл має вміти зберігати знайдені маршрути — повернуті маршрути з API в Redis.

**Основні функції:**
- Кешування маршрутів у Redis
- Збереження результатів API-запитів
- Управління життєвим циклом кешованих даних
- Швидкий доступ до раніше знайдених маршрутів

### proxy/
Тут міститься інформація та налаштування проксі.

**Компоненти:**
- `proxyConfig.ts` - конфігурація проксі-сервера
- `proxyServer.js` - основний проксі-сервер
- `proxyClient.ts` - клієнт для роботи з проксі
- `start-proxy.sh` - скрипт запуску проксі

**Призначення:**
- Проксування запитів до зовнішніх API
- Обхід обмежень CORS
- Управління трафіком та навантаженням
- Логування та моніторинг запитів

## Взаємодія компонентів

1. **roadOptimizer** використовує API через **proxy** для отримання даних
2. **redisRouteService** зберігає результати роботи **roadOptimizer**
3. **proxy** забезпечує безпечний доступ до зовнішніх сервісів
